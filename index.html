PawFinder Case Study

PawFinder is a React-based dog explorer designed to make discovering dog breeds simple, engaging, and easy to navigate.

The Brief

The project required working with an API, displaying dynamic data, managing loading and error states, and creating a responsive interface. I focused on the UI, loading experience, and footer, while contributing to the wider React implementation.

The Problem

Users need more than data; the interface must communicate when information is loading, when something has gone wrong, how to navigate information, which dogs are saved as favourites, and how the experience adapts at all screen sizes.

My Role

My contribution focused on UI design, loading experience, footer structure, and ensuring the app remained responsive and easy to use. I also worked with shared state through Context API and reusable React components.

Outcome

PawFinder helped me move beyond earlier React experience by working with Context API, custom hooks, API-driven interfaces, routing, and responsive design. The project also emphasized how development and design thinking work together.
